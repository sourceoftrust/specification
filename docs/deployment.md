# Deploying the reference website

The site is generated by Astro as static HTML and CSS. Cloudflare Workers
serves the generated files using the `ASSETS` binding. The small Worker handler
provides the canonical host redirects.

## Build and verify

Use Node.js 22.12 or later and install the versions recorded in the lockfile:

```sh
npm ci
npm run build
npm run verify
npm run preview
```

The generated site is in `dist/`. The verification script checks the editorial
pages, internal links, canonical metadata, JSON-LD, sitemap, robots.txt, external
stylesheets, and redirect behavior.

## Review deployment configuration

`wrangler.jsonc` defines the Worker entry point, asset directory and binding,
404 behavior, trailing-slash handling, and custom domains. The reference site's
canonical URL is `https://sourceoftrust.org`; `www` redirects permanently to
HTTPS on that host while preserving paths and query strings.

For an independent deployment, change the Worker name and domain configuration
and update the canonical origin consistently in the Astro configuration,
layouts, sitemap, robots.txt, redirect handler, and verification script. Obtain
authorization before attaching domains or changing existing deployment settings.
Keep credentials outside the repository.

## Deploy

Authenticate Wrangler with an account authorized to deploy the target Worker.
Review the configuration before running:

```sh
npm run build
npm run verify
npx wrangler deploy --dry-run
npm run deploy
```

The final command publishes the build and applies the configured domains.
A dry run does not publish the site.

## Check the published result

Check both editorial pages, applied styles, canonical URLs, and JSON-LD.
Confirm that robots.txt and sitemap.xml are accessible, unknown paths return
404, HTTPS has a valid certificate, and HTTP and www redirects reach the
canonical HTTPS host with paths and query strings preserved.

Repository CI builds and verifies the site; it does not deploy it.
